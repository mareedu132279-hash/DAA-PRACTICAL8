# DAA-PRACTICAL8
Summary

The graph was implemented using an adjacency list with vertices and edges entered by the user.
DFS and BFS algorithms were implemented to traverse and search the graph from a given starting vertex.
The program displays the traversal order along with the time and space complexity of both algorithms.

Conclusion

DFS uses recursion to explore vertices deeply, while BFS uses a queue to explore vertices level by level.
Both algorithms efficiently traverse the graph with a time complexity of O(V + E).
Hence, DFS and BFS are useful graph-searching techniques for solving various problems.
